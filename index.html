About

I'm doing a Master of Professional Studies in Applied AI at Northeastern (2026 to 2027), after a B.S. in Electrical Engineering & Computer Science at IISER Bhopal. Most of my work now is LLM systems: agents and the tooling around them, evaluation harnesses, retrieval, and the infrastructure underneath, like inference servers, gateways, and distributed training.

I care more about the parts that don't demo well, like evals, failure modes, and deployment constraints, than about a clean one-off result. Understanding why an agent breaks, and building the scaffold that stops it, is the work I actually enjoy.

Before that, my undergrad research was in multi-agent reinforcement learning and robotics: MARL for swarm exploration at MOON Lab and an autonomous cleaning robot at DUDE Lab. In 2026 I did two industry-sponsored projects with OpenEye Scientific Software (Cadence) and built TenderMind at the Red Hat Hackathon.

mcp-probe

Recording proxy that records and replays MCP sessions

Drop it in front of any stdio MCP server to get a full session transcript plus latency and estimated token cost per tool call, then replay the session against a changed server and diff what moved. Passes bytes through untouched (a test checks this), and --fail-on-change turns a recorded session into a CI regression test. Zero dependencies, 24 tests.

Python (stdlib only) / MCP / JSON-RPC

JUL 2026PERSONAL

mcp-eval

Scores how well a model actually uses your MCP tools

Point it at a server and a YAML file of tasks. It scores tool selection, argument validity and values, and whether the model correctly calls nothing when nothing is needed. It also measures what tool schemas cost in tokens, and an ablation mode strips each description to show which ones are load-bearing. Hand-rolled JSON-RPC client, CI gate, 46 tests. Record with mcp-probe, score with mcp-eval.

Python / Anthropic API / JSON-RPC / pyyaml
